# HR Database & Analytics — PostgreSQL

**Автор портфолио: Ксения Самохина**  
[English README](README.md)

Учебный проект HR-базы данных на PostgreSQL с **вымышленными данными**. 

## Файлы

- `HR_Database_Analytics.sql` — **полный SQL-скрипт**: таблицы, данные, запросы, функции, представления и оконные функции.
- `HRM_Samokhina_Ksenia.backup` — резервная копия базы PostgreSQL.
- `Analytics_After_Restore.sql` — четыре безопасных аналитических SELECT-запроса для восстановленной базы.
- `README.md` — английская версия.

## Способ 1. Создать базу с нуля

1. Открой pgAdmin и создай **новую пустую базу** (например, `HR_Portfolio_Fresh`).
2. Выбери её → **Query Tool** → открой `HR_Database_Analytics.sql`.
3. Запусти файл **один раз**. Он создаёт схему `staff2`, таблицы, тестовые данные, функции и выполняет учебные запросы.
4. Посмотри таблицы в **Schemas → staff2 → Tables**.

**Не запускай полный SQL-файл на существующей или восстановленной базе**: в нём есть создание таблиц, вставки и обновления. Повторный запуск не предусмотрен. **Полный новый скрипт пока проверен статически, но не прогнан целиком на живом сервере PostgreSQL в этой среде.**

## Способ 2. Восстановить готовую базу

1. Создай ещё одну пустую базу в pgAdmin (например, `HR_Portfolio_Restored`).
2. Правой кнопкой по базе → **Restore** → выбери `HRM_Samokhina_Ksenia.backup`, формат **Custom** → **Restore**.
3. Открой схему `staff2`: ранее проверены 9 заполненных таблиц (76 строк).
4. Открой `Analytics_After_Restore.sql` через Query Tool и запусти четыре аналитических запроса.

Ранее резервная копия была успешно восстановлена в отдельную тестовую базу, а четыре аналитических запроса проверены в pgAdmin. Полный новый SQL-файл ещё требует теста на чистой базе.

**Данные вымышленные.**
